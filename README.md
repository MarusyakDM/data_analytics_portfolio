### 2. SQL: Продвинутые аналитические отчеты
* **Папка:** `01_sql_advanced`
* **Файлы:**

* **Описание:** Написание сложных аналитических запросов для бизнеса.

  * *Сводный отчет по клиентам* — анализ клиентской базы, VIP-сегментация, тренды.
  * *«Кто кормит компанию»* — оценка вклада каждого сотрудника (доля в отделе, накопленная доля Парето, ROI, лояльные и «общие» клиенты, пропуски месяцев, максимальные перерывы между заказами). **Запрос использует `generate_series`, `LATERAL`, `RANK`, `LAG`, `SUM() OVER` и корректно обрабатывает сотрудников без заказов и пустые отделы.**
* **Технологии:** SQL (PostgreSQL), CTE, Оконные функции (ROW_NUMBER, RANK, LAG, SUM OVER), LATERAL, generate_series, COALESCE, NULLIF.
* [RFM-сегментация клиентской базы (Q1 2024)](01_sql_advanced/04_rfm_customer_segmentation.sql)
* **Описание:** Написание сложных аналитических запросов для бизнеса. 
  * *Отчет по эффективности отделов* — расчет окупаемости, поиск лучших менеджеров.
  * *Сводный отчет по клиентам* — анализ клиентской базы, VIP-сегментация, тренды.
  * *«Кто кормит компанию»* — оценка вклада каждого сотрудника (доля в отделе, накопленная доля Парето, ROI, лояльные и «общие» клиенты, пропуски месяцев, максимальные перерывы между заказами). **Запрос использует `generate_series`, `LATERAL`, `RANK`, `LAG`, `SUM() OVER` и корректно обрабатывает сотрудников без заказов и пустые отделы.**
  * *RFM-сегментация* — маркетинговый анализ клиентской базы (Recency, Frequency, Monetary). Расчет скоров от 1 до 5, присвоение сегментов (Champion, Loyal, At Risk, Hibernating и др.), сводный отчет по сегментам (кол-во клиентов, выручка, доля в общей выручке). **Запрос использует множественные CTE, `LEFT JOIN` для клиентов без заказов, `COALESCE`, `CASE` для скоринга и `SUM() OVER()` для расчета долей (Парето).**
* **Технологии:** SQL (PostgreSQL), CTE, Оконные функции (ROW_NUMBER, RANK, LAG, SUM OVER), LATERAL, generate_series, COALESCE, NULLIF, CASE, TO_CHAR.
