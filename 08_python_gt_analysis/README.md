# Оценка эффекта модернизации осевого компрессора ГТУ

## Бизнес-задача
Оценить прирост располагаемой мощности и экономический эффект от модернизации 
лопаточного аппарата компрессора (рост КПД на 1.5 п.п.) по данным САУ.

## Данные
- 10 922 точки телеметрии, шаг 3 мин (проверено: пропусков и дубликатов нет)
- 14 параметров: мощность, расход топлива, температуры/давления, ВНА, внешние условия
- Фактические цены РСВ (дневной индекс, 1-я ценовая зона)

## Методология
1. Разметка и исключение переходных режимов (останов / простой / пуск)
2. Фильтрация номинального режима (N > 310 МВт, ВНА > 86%) → 4 164 точки
3. Поправочные кривые: регрессия по 5 внешним параметрам → приведённая мощность
4. Термодинамический пересчёт (CoolProp): энтальпии, работа компрессора, новая мощность
5. Placebo-проверка: фоновая разница периодов, t-test
6. Экономика: энергия за 3-мин интервал × цена РСВ → экстраполяция на год
7. Анализ чувствительности по K_comp

## Результат
- **Прирост мощности:** +2.64 МВт (+0.86%) при K_comp = 0.5
- **Годовая выручка:** ≈ 14.98 млн ₽/год
- **КПД компрессора:** 85.6% → 87.1% (+1.5 п.п.)
- **Фоновая разница** 0

**Прирост мощности ~в 3 раза превышает фоновый дрейф периодов.**

## Ограничения модели
- Дневной индекс РСВ 1-й ценовой зоны (не почасовые цены)
- Ноябрьские цены экстраполированы на год
- Простой турбины: 1200 ч/год 
- K_comp = 0.45–0.55
